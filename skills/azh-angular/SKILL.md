## Project structure
- The project follows a strict feature-based architecture with clearly defined boundaries between pages, features, shared resources, core infrastructure, and theme. Read [project-structure.md](references/project-structure.md).


## Naming Conventions
- Use the **classic role-suffix** style — class names and file names MUST keep role suffixes (`ProductListComponent` / `product-list.component.ts`, `AuthService` / `auth.service.ts`). Do NOT apply the suffixless "Intent over Role" style. Read [naming-conventions.md](references/naming-conventions.md).
