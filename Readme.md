# AI Settings

## Installation

Install Claude Code:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Install plugins:

```bash
chmod +x scripts/external-setup.sh
./scripts/external-setup.sh
```

Set up global Claude Code instructions:

```bash
chmod +x scripts/guides-setup.sh
./scripts/guides-setup.sh
```

Link local skills into the global Claude Code skills directory:

```bash
chmod +x scripts/skills-setup.sh
./scripts/skills-setup.sh
```
